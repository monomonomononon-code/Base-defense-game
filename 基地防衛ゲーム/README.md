# OUTPOST — 野営地と遠い地平

ブラウザで遊べる、見下ろし型の「拠点防衛＋遠征RPG」です。React + TypeScript + Vite、戦場はCanvas 2D、UIはCSSとSVG。外部画像、音源、APIキー、バックエンドは不要です。

## 起動方法

Node.js 20.19以上（22 / 24 LTS推奨）で実行してください。

```sh
npm install
npm run dev
```

[http://localhost:5173](http://localhost:5173) を開きます。同じWi-Fi内のスマホからはターミナルのNetwork URLにアクセスできます。接続にはPCのファイアウォール設定が影響する場合があります。

```sh
npm test         # ゲームロジック・進行・保存の自動テスト
npm run build   # TypeScriptチェック＋本番ビルド
npm run preview # 本番ビルドのローカル確認
npm run balance # 全55レベルの数値をdocs/levels.csvに再出力
npm run simulate:all # Lv1→55・ビルド・購入除外の109ケースを再計測
npm run simulate:report # 保存済みログから監査レポートを再生成
```

スマホでは左のスティックを押したまま、別の指で右下の回避・旋風撃・回復を同時に操作できます。戦闘通知は画面上部に最大2件だけ表示され、約5秒で自動的に消えます。

画面右上のミニマップは黄緑＝主人公、赤＝敵、黄色＝発見・資源・宝箱、淡緑＝帰還地点。木や岩、川は記号的な背景で、移動を妨げません。マップ・装備・設定を開いている間や別タブに移った間は時間が止まります。戻った際は「冒険を再開」を押してください。

## ゲームルール

### 最初の5分

1. 「防衛を開始」を押して、小さな家を守ります。敵へ近づくと自動射撃します。
2. 倒した敵からコイン・経験値・木材を獲得。右側の「＋」で攻撃力やHPを強化しましょう。準備中に家の近くにいると主人公と家が回復します。
3. 兵士を雇うと自動迎撃してくれます。3ウェーブ目のボスは赤い範囲予兆を出すため、移動や回避で避けて攻撃します。
4. ボスを倒すと遠征マップが解放。11地域すべてへ出発できます。
5. 最初は平原か森林を探索。資源に近づいてE、宝箱・発見・敵前哨地は守護エリートを倒してからEで調べます。
6. 好きな時に帰還し、素材とコインを施設・装備・スキルへ投資。より危険な地域へ進みます。

### 防衛

- 最初は主人公中心。兵士、弓塔、砲台の増設と訓練で雑魚の処理を任せられます。
- エリート・ボス・追跡者・破城獣に対する守備隊の威力は42%。主人公の射撃と旋風撃は減衰しません。
- 3ウェーブごとにボスが出現。防衛レベルは主人公Lv、拠点Lv、発見・討伐済み地域を参照し、ウェーブ進行によって敵数や特殊敵も増えます。格上地域を訪れただけでは防衛が急激に難化しません。
- 主人公の攻撃力・速度・射程・HP・移動速度、兵士の雇用・訓練、防壁・弓塔・砲台・回復施設・倉庫・鍛冶屋・拠点Lvを強化できます。
- 強化は拠点内なら戦闘中も可能。回復施設は家の近くで持続回復、倉庫は獲得量増加、鍛冶屋は主人公の攻撃力を増加し、装備鍛造費も軽減します。回復施設は遠征時の回復量とクールダウンも改善します。
- 防衛成功で補給2個を獲得（最大12個）。遠征時に1個使うと攻撃+25%以上・経験値+20%・被ダメージ12%軽減。拠点Lvと兵士訓練で攻撃支援が増え、回復施設があれば補給中の遠征で持続回復します。補給がなくても遠征できます。

### 遠征と世界

**レベルで地域への進入を禁止しません。** 最初の防衛ボスを撃破した後は、Lv8でもLv20地域や最終地域に入れます。敵は指数的に強くなり、格上エリートの予兆攻撃は一撃で倒されることもあります。射程・移動・回避・装備で背伸び狩りを狙えます。

地図の分岐線は世界のつながりを示す目安です。移動はマップで行き先を選択するエリア方式で、線の順に攻略する必要はありません。各地域には通常敵、3体の守護エリート、資源2か所、宝箱、発見イベント、敵前哨地、帰還地点があります。1回の遠征で14体倒すとその地域のボスが出現。再訪問で再戦・再採取できます。発見による解禁と前哨地制圧の恒久効果は地域ごとに一度だけです。

### 成長・装備

- 主人公はLv1〜55。経験値で基礎攻撃力とHPが上がり、レベルアップ時に全回復します。自分より大幅に低Lvの敵は獲得経験値が減衰します。
- 武器は攻撃力、防具はHP、護符は会心率と経験値獲得量を増加。武器+6/+12/+18では名称が変わり、追加倍率1.13/1.26/1.39が付きます。防具も同じ節目で被ダメージ6/12/18%軽減。エリート・ボス・宝箱から手に入れ、現在より強いものを自動装備します。同等以下の装備はコインへ変換されます。
- 装備は素材とコインで鍛造可能。初期上限+4、鉱山発見で+12、山岳発見で+14、廃都市発見で+18。ドロップ品は鍛造上限に関係なく装備できます。
- 旋風撃は9段階。中盤以降の強化に希少結晶を使用します。
- 最終地域のボス「地平を喰らう王」を討伐するとクリア。Lv55到達前でも討伐可能で、クリア後も自由に探索できます。

### 襲撃と第二拠点

遠征解放後、実プレイ時間で約5分ごとに襲撃を判定します。守備力と耐久力が十分なら守備隊が小規模襲撃を自動撃退し、拠点耐久力が最大15%低下します（防壁で軽減）。守備力不足、または3回に1回の大規模襲撃では75秒間の帰還猶予を表示。期限に達すると自動的に拠点へ帰還し、防衛戦が始まります。敵前哨地を初めて制圧すると、以後の襲撃間隔が地域ごとに25秒延長されます（合計最大200秒）。

荒野の高台を発見後、拠点でマップを開き、600コイン・鉄35で第二拠点を建設可能。施設・兵士・ウェーブ・耐久力は個別ですが、主人公Lv・装備・スキル・主人公強化・訓練・鍛冶屋の効果は共有されます。第二拠点の現地施設・兵士のアップグレード費用は28%引き。共有される恒久強化は通常価格です。襲撃・遠征帰還は現在選択中の拠点を対象とします。

### セーブ・戦闘不能

`localStorage` の `outpost-horizons-v1` に約8秒ごと、購入・発見・帰還・防衛完了時などに保存します。レベル、経験値、コイン、素材、装備、訪問地域、発見、討伐、前哨地、両拠点の状態、兵士・施設Lv、スキル、補給、設定、襲撃タイマーを保存します。外部サーバーには送信しません。

- 再読込は選択中の拠点から。進行中の敵・弾・位置・クールダウン・採取地点の一時状態は保存しません。未完了ウェーブは同じウェーブの最初からです。
- 戦闘不能・拠点陥落時はコインの8%を失い、拠点へ復帰。素材・装備・経験値・解禁は維持、主人公と拠点は修復されます。
- セーブはブラウザとURL（オリジン）ごとに独立しています。別の端末やlocalhostからVercelへのデータ同期はありません。
- 設定から手動保存と、確認付きの全リセットが可能。ストレージが使えない場合は保存エラーを表示します。

### 効果音

通常攻撃、命中、敵撃破、被弾、コイン、宝箱、レベルアップ、強化、施設建設、UI決定、購入不可、Wave開始、ボス出現・撃破、地域解禁、ゲームオーバーに効果音があります。設定画面で0〜100%の音量変更とミュートができ、設定はセーブされます。

音は `src/game/audio.ts` がWeb Audio APIのオシレーターから実行時に生成します。外部音源、生成済み音声ファイル、第三者素材を同梱していないため、音源ライセンスの帰属表示は不要です。高頻度の攻撃・命中・コイン音には種類別の再生間隔を設け、全体の同時発音を最大10音に制限しています。ブラウザの自動再生制限に従い、最初のクリックまたはタッチ後から再生されます。

### BGM

通常曲「朝露の小径」（96 BPM・80秒）と戦闘曲「灯りを守る足音」（128 BPM・60秒）の2曲をループ再生します。共通の旋律と、柔らかな撥弦・笛・弦の響きを持つオリジナル曲です。戦闘曲には控えめな太鼓と動きのある伴奏を加えています。

拠点の準備中・穏やかな探索中は通常曲、防衛Wave・近くの敵との戦闘・ボス出現中は戦闘曲。戦闘へ1秒、通常へ2.5秒のクロスフェードで切り替えます。遠征では敵から離れて8秒間平穏になると通常曲へ戻り、短い接敵による切替の連発を抑えます。

設定の「BGM」で音量0〜100%・ミュートを変更できます。SEとは別管理で自動保存され、旧セーブはBGM40%で補完します。最初のクリック・タップ・キー操作で開始。設定・一時停止中は音量を下げ、別タブや画面ロックなどページ非表示中は停止します。ブラウザが復帰時の再開を制限した場合は、もう一度タップしてください。

外部音源・サンプルは使用せず、専用に作成した旋律と波形合成コードからWeb Audio APIで生成します。音源のダウンロードや第三者の音源ライセンスは不要です。仕様・検証範囲は [BGM実装と検証](docs/bgm.md) を参照してください。

## バランス調整箇所

基本は `src/game/data.ts` を変更します。

- `BALANCE`：成長、HP、射程、クールダウン、襲撃、装備、ドロップ。
- `LEVELS`：全55レベルの必要経験値・基礎HP・攻撃力を生成する数値テーブル。
- `ENEMIES` / `enemyStats()`：10役割の基礎能力とレベル倍率。
- `REGIONS` / `ROUTES`：適正Lv帯、敵構成、素材、イベント、ボス、分岐地図。
- `UPGRADES`：全14強化の価格、価格倍率、上限、素材、発見条件。

倍率の詳しい意味と進行例は [docs/balance.md](docs/balance.md) を参照してください。

## GitHubとVercelへのデプロイ

1. GitHubで空のリポジトリを作成します。
2. このフォルダで以下を実行します（URLは自分のリポジトリへ置き換え）。

```sh
git init
git add .
git commit -m "Build Outpost defense RPG"
git branch -M main
git remote add origin https://github.com/YOUR_NAME/outpost-horizons.git
git push -u origin main
```

3. Vercelの「Add New → Project」からリポジトリをImportします。
4. Framework Presetは **Vite**、Build Commandは **npm run build**、Output Directoryは **dist**。Root Directoryはこのプロジェクトのルートを指定します。環境変数は不要です。
5. Deployを実行します。以後GitHubへpushすると自動で再デプロイされます。

Vercelへの公開やGitHubへのpushは、このプロジェクトの生成時点では行っていません。ゲームは静的ファイルのみで動き、Vercel Functionsやデータベースを必要としません。

## 検証の範囲

自動テストでは全Lvの成長・全地域定義・格上入場・3ウェーブとボス・発見解禁・帰還・襲撃・第二拠点・購入・保存を確認しています。序盤1ウェーブとLv55装備構成での最終ボス戦は、実際の自動射撃・回避移動・クールダウンによるシミュレーションも行います。PC / スマホ幅のブラウザ表示、序盤防衛、購入、保存復元も確認しています。長期のLv55到達を人間が通しプレイした保証ではありません。


Lv1からの実エンジンシミュレーションは本編55ケースと購入除外54ケースを実施。通常往復・第二拠点・反応遅れモデルの45/45ケースでLv55と最終ボス討伐へ到達しました。主要4ビルドのLv55時間は約42〜49分、初見の設計目安は60〜90分（人間の実測ではありません）。防衛だけの方針はLv51で停滞し打切りとなり、遠征の解禁を使う必要性が残ります。最終ボスはLv55以前にも倒せます。

詳細は [バランス監査レポート](docs/balance-audit.md) を参照してください。ログには乱数seed・各Lvの資産・購入履歴・死亡・ソースハッシュを記録しており、再計測できます。

## エンドレスモード「果てなき地平」

**Lv55到達と最終ボス討伐の両方**で解禁されます。画面上部の「果てなき地平」から出発します。ボスをLv55以前に倒していた場合は、Lv55になった時点で解禁。主人公・装備・本編クリア・両拠点の施設は維持します。

- **エンドレス防衛**：現在の拠点を使用。5Waveごとにボスが登場し、次の5Waveで敵レベル・HP・攻撃力・総出現数・報酬が上昇します。クリア後6秒で次のWaveへ。途中帰還も可能です。本編の防衛Waveは増えません。
- **エンドレス遠征**：11地域の地形・敵構成を流用し、地域、装飾、資源、宝箱、イベント、守護エリートの配置を組み替えます。規定数の敵を倒すとボスが出現。ボス討伐後「次の危険度へ」で続行するか、帰還して強化できます。
- **報酬**：コイン・素材倍率は初期1.5倍から段階的に上昇。エリートのレア発見率も12%から最大65%へ上昇し、ボスと宝箱はレア確定。レア報酬は「超越の欠片」と結晶です。欠片はクリアや遠征の補給庫からも獲得します。
- **超越鍛造**：コインと欠片を使う上限なしの恒久強化。エンドレス内だけ、主人公攻撃・HP・守備隊威力・拠点の実効耐久を増加。本編の装備上限・施設価格・戦闘倍率は変わりません。
- **最高記録**：クリアした最高Wave・最高危険度を保存。再読込は通常拠点からで、最高記録の次から再挑戦できます。「1から周回」で低い段階の報酬を集め直すことも可能。戦闘途中の敵や位置は保存しません。
- **保存**：最高記録、超越鍛造、所持欠片、累計獲得コイン・素材・欠片・レア発見数を自動保存。通常の所持金・素材にも加算されます。累計は消費や死亡で減りません。死亡時は従来どおり所持金8%を失います。
- 挑戦中は本編の襲撃タイマーが停止します。襲撃予告中は防衛を済ませてから出発してください。旧セーブは新しい記録を0で補完します。
