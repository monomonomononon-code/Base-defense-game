# BGM実装と検証

## 音楽

| 用途 | 曲名 | BPM / 拍子 | ループ | 音色 |
| --- | --- | --- | --- | --- |
| 通常 | 朝露の小径 | 96 / 4拍子 | 32小節・80秒 | 柔らかな撥弦、息の長い笛、薄い弦、控えめな低音 |
| 戦闘 | 灯りを守る足音 | 128 / 4拍子 | 32小節・60秒 | 共通音色に細かな撥弦と軽い太鼓を追加 |

D majorの共通モチーフ「D E F# A / F# E D」を使った本プロジェクト専用の旋律です。4小節ごとに笛が休み、後半で薄い弦が入る構成。重いロックや過大なオーケストラ、鋭い金属音、外部サンプルは使用していません。音色も正弦波の加算合成による自作で、第三者音源の購入・帰属表示を必要としません。

`src/game/musicScore.ts` に譜面、音色、BPM、音量、フェード時間を集約。22,050 HzのモノラルAudioBufferを初回操作後に生成し、2曲合計で約12.4 MBを使用します。生成処理を分割して入力への長いブロックを避けます。残響の末尾を先頭へ折り返し、ネイティブのループ再生で継ぎ目を接続。ゲームの乱数を消費しません。

## 場面と設定

- 防衛：Wave中は戦闘曲、準備中は通常曲。エンドレスも同じです。
- 遠征：近くの敵、射撃、被弾、生存ボスを検出すると戦闘曲。脅威のない時間が8秒続けば通常曲。
- ワールドマップは通常曲。設定・装備・一時停止中は現在曲を維持し、BGMだけ45%へ下げます。
- 通常→戦闘は1秒、戦闘→通常は2.5秒のクロスフェード。途中で判定が逆転しても現在の音量から継続します。
- BGM音量・ミュートはSEから独立し、セーブの `settings.bgmVolume` / `bgmMuted` に保存。旧セーブは40%・ミュートなしに補完。不正な値は既定値または0〜1へ補正します。
- pointerdown / touchend / keydown内でAudioContextを起動・再開。非表示時はsuspend、復帰時はresumeを試み、拒否された場合も次の操作で再試行します。二重起動せず、破棄時に音源とContextを解放します。

## 2026-09-14の検証

- `npm test`：48/48成功。BGM5テストを追加し、旧セーブ互換、場面判定、波形の有限性・継ぎ目、フェード反転、独立音量・ミュート、復帰、未対応環境を検証。
- `npm run build`：TypeScriptとVite本番ビルド成功。
- `npm run simulate:all`：本編55条件＋購入除外54条件を再実行。通常往復・第二拠点・一般操作近似45/45条件でLv55と最終ボス討伐へ到達。ゲーム数値・戦闘処理は変更していません。
- 実ブラウザ（Codex内蔵Chromium）の1280px幅と360×740px幅で検証ページを実行。初回操作後に生成（約1.1秒）、通常・戦闘双方の音声出力をAnalyserNodeで測定。1秒/2.5秒のフェード、音量15%、ミュート/音量0の無音、非表示・復帰、音源の二重生成なしが全項目成功。
- ゲーム本体の360px幅で設定表示を確認。BGM25%・ミュートを設定して再読込後も維持し、SE55%・再生状態は変化なし。BGMを40%・再生へ戻し、防衛開始も確認。

ブラウザで再検証する場合は `npm run dev` 後に `/tests/bgm-browser.html` を開き、「タップして再生テスト」を押します。検証ページは開発時専用で、本番ビルドには入りません。実音声経路の信号とループ設定を確認するもので、音楽の好みや物理スピーカーの音質を判定するものではありません。

スマホ幅はデスクトップChromiumの表示幅変更で確認しています。iOS Safari / Android実機でのタッチ・画面ロック・音声出力はこの環境では未検証です。初回タップ、アプリ切替後の再開、端末の消音モードとの関係は実機での追加確認が必要です。
