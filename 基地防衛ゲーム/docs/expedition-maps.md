# 分岐する遠征マップ

## 遊び方の変化

「ふたつの橋」「三叉の森道」「環状の廃道」「湿原の合流点」の4テンプレートを追加。左右反転と座標の小変化を組み合わせ、通常遠征とエンドレス遠征で使用します。入口は南、主の広場は北です。

| ルート | 選ぶ理由 | 危険・距離 |
| --- | --- | --- |
| 赤い直通路 | 主の広場へ短く到達 | 敵配置の重み4、前哨地エリート |
| 緑の外周路 | 資源2か所を回収 | 配置の重み1、赤い道の1.5倍以上の道のり |
| 金の宝箱路 | 従来の装備・コイン・素材報酬 | 配置の重み3、宝箱エリート |
| 紫の袋小路 | 地域の発見・解禁 | 発見エリート。引き返して合流路を利用 |

主は従来の規定討伐数（本編14体）で北の広場に出現。単に北へ歩くだけでは出現しません。宝箱・資源・イベント・前哨地の個数と報酬額、レベル・能力・施設・価格は変更していません。

## 見た目と実際の移動

道のグラフを通行判定にも使用します。明るい道・広場・橋は歩けますが、外側の暗い森・岩場は通行不可。道端の茂み・石、橋の欄干、沼の渡り石、廃道の石畳が地形の違いを示します。道は幅150、主の広場は半径300を確保し、狭い迷路やボス戦の逃げ場不足を避けています。

主人公と敵は同じ通路を移動し、回避は小刻みな判定で地形を飛び越えません。弾は地形で止まり、地形越しの自動射撃・旋風撃は行いません。地形変更は遠征にのみ適用し、拠点防衛の移動や操作キーは維持しています。

敵は従来の出現間隔・同時数上限で道に配置。主人公の足元240以内への出現と、同じ場所への過密出現を避けます。離れた未交戦の巡回敵は待機し、近づくか攻撃すると追跡します。敵の経路は約0.6秒ごとに更新し、橋・分岐を通って追跡します。

ミニマップで色分けした分岐・合流と主の広場を表示。「ルートを見る」で一時停止し、拡大図と日本語の凡例を確認できます。セーブ形式は変更せず、従来どおりロード後は拠点から再開します。

## 調整箇所

- `src/game/expeditionMap.ts`：4テンプレート、道の接続、幅・広場、敵配置、通行・遮蔽判定、経路探索。
- `src/game/expeditionRender.ts`：道・橋・沼・森・廃道の描画。
- `src/game/engine.ts`：遠征への統合、敵・主の配置、移動と弾への地形適用。
- `src/RouteMap.tsx` / `src/App.tsx`：拡大地図と案内。
